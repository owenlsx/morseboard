MorseBoard for iPhone

Text in Morse.

Type dots and dashes directly, or translate Morse sequences into letters using two large keys or a single timed key.

Enable MorseBoard

  1. Open Settings on your iPhone.
  2. Choose General → Keyboard → Keyboards → Add New Keyboard.
  3. Select MorseBoard.
  4. Tap or hold the globe key in any ordinary text field, then select MorseBoard.

MorseBoard does not require Full Access.

Keyboard not showing?

Check that MorseBoard is enabled in Keyboard settings. Password fields and some apps use the system keyboard by design.

Change how it types

Tap the gear on the keyboard to choose one or two keys, symbols or letters, dot style, and timing from 5–30 WPM.

Single-key timing

Tap for a dot and hold for a dash. In letters mode, pause briefly to finish a letter. Lower WPM is easier while learning.
